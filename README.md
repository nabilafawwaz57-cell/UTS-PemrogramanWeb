## 🌷 About The Project

**BookStore** is a simple online bookstore website developed as a project for the Midterm Examination of Web Programming 1.

This website simulates an online bookstore management system that allows users to manage book catalogs, create orders, track deliveries, and view transaction reports.

The project is built using HTML, CSS, and JavaScript, with Local Storage for storing transaction data.

## 🎀 Main Features

**01. Login Page**
- Email and password validation.
- Login success and error notifications.
- Forgot Password popup.
- Registration popup.

**02. Dashboard**
- Greeting based on current time.
- Navigation to all website features.

**03. Stock / Book Catalog**
- Display book information.
- Show book title, author, price, and stock.
- Add new books dynamically.

**04. Checkout / Order**
- Add book orders.
- Edit and delete orders.
- Customer information form.
- Payment method selection.
- Automatic Delivery Order number.
- Total payment calculation.

**05. Delivery Tracking**
- Search orders using DO numbers.
- Display customer and delivery information.
- Show delivery progress.

**06. Order Report**
- Display saved customer orders.
- Show total payment and payment method.

**07. Transaction History**
- Display previously saved transactions.
- Show customer information and order status.

- Clean forms and tables.
- Consistent styling across pages.

## 📝 Project Notes

This project is a front-end simulation developed for academic purposes. It does not currently use a backend server or external database.

Transaction data is stored locally in the browser using Local Storage.
